# Cross-platform wireless startup optimization

Goal: generate new GWRT wireless configuration once, preserve existing user/Mesh settings, remove competing runtime rewrites, and avoid irrelevant first-boot work. Implementation lives in this isolated NAS snapshot; synchronize only verified changed files. No firmware builds or device operations.

1. Add a shared generator policy enabled by the lightweight gwrt-wifi-defaults package, required by device-defaults and the full/lite themes. Choose SSID/MAC suffix, encryption, country and supported 5 GHz channel/width while creating new radios. Store available channels in wifi-detect; use actual capability and hardware path, not radio numbers. Non-GWRT defaults remain unchanged.
2. Reduce the old wireless uci-defaults script to an SS-01 readiness barrier; let the existing detector/generator create configuration. Preserve the serialized SS-01 worker. Turn obsolete naming/5G hotplug hooks into immediate no-ops, so package upgrades retire them safely. Keep the old explicit helper callable without routine boot invocation.
3. Limit IPQ6018 calibration fallback to boards actually using it; preserve overlay READY/guard/sync checks. Stop normal-boot SSID/channel rewriting and idle phy polling. Trigger only the pending SS-01 worker.
4. Retry only failed offline APK installs and keep the final overlay pending until installation succeeds. Select the final wifiroam overlay once, defer its explicit service activation until configuration/copy work succeeds, and preserve existing Mesh role/settings. Retain the known GWRT-created backhaul WDS migration. Do not expand into unrelated firewall/LED changes without a demonstrated need.
5. Add failing behavior regressions first. Run actual ucode generator with isolated filesystem/UCI inputs, cross-platform/path/capability and saved-config cases; shell regressions cover disabled/user/Mesh settings, no-wireless boards, APK retries, SS-01 serialization, service failures, and calibration reboot persistence. Compile/check changed scripts and review diff.
6. Record exact checks/limits. Selectively synchronize verified changes after checking original files still match the snapshot baseline. Preserve concurrent changes. Do not claim the CS-02 missing phy or CS-07 red light is fixed without device evidence.
