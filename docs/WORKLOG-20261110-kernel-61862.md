# WORKLOG 2026-11-10 — 内核继续更新到 6.18.62（GWRT 构建树）

## 背景与决策

- kernel.org 于 2026-11-06 发布 **6.18.62**（longterm）。6.18.61 因
  CVE-2026-100080/81/82 未发布、由 .62 直接取代；`ChangeLog-6.18.61` 累积
  **1001 个 commit**，所以 .60 → .62 实际跨了一整个大 stable 批次，不是小版本微调。
- OpenWrt / ImmortalWrt 官方 master 仍是 **6.18.60**（最后 bump 2026-10-30）；
  bump 到 .62 的 [openwrt/openwrt#26530](https://github.com/openwrt/openwrt/pull/26530)
  截至本次仍 **open 未合并**。这次是抢在上游前面更新。
- 用户要求「继续更新」，选择**先更 GWRT 构建树**（当前 SS-01 用），不动
  `mark/immortalwrt` 源码树（仍 6.18.55），不触发编译、不刷机。
- 隔离分支 `kernel-61862-261110`，基于 `ss01-theme-ethernet-261109` HEAD
  `5f0dcdf2`；原 SS-01 验证分支未改动，随时可切回。

## 做法

- PR #26530 共改 70 个文件。在 GWRT（ImmortalWrt 快照 + GWRT 私有补丁）上逐段
  `git apply --check`，**30 个可干净套用**，其余因补丁集不同或文件缺失不适用；
  整包 diff 直接 apply 会失败，不能照搬。
- 应用可套用的 30 段：删除 2 个已上游化 backport（`503-01` ksmbd keepalive、
  `755` HORACO SFP quirk）、rebase `441` spi-qpic-snand 与 `739-03` pcs-mtk-lynxi，
  其余为上游自动 rebase 的行号刷新（generic / mediatek / bcm27xx / lantiq /
  octeon / siflower）。
- PR 的 mac80211 `160-backports-sockaddr_unsized` 与 ltq-ifxos `6,18,57` guard
  改动对本树**不适用**：本树没有 .57 引入的那两个适配，且 6.18.62 内核里
  `sockaddr_unsized` 已被 revert、并不存在。未套用。
- GWRT 私有 NSS 补丁手工 rebase：
  - `qualcommax/0600-1`：6.18.61 重构了 `ip_gre.c` 的 GRE flags
    （`__gre_xmit()` 新增 `flags` 形参、改用局部 `flags`），按 6.18.62 源码重新
    生成 `ipgre_xmit` / `gre_tap_xmit` 两个 hunk。修好后此前**级联失败**的
    `0600-7` / `0604-1` / `0604-2` / `0606-1` 全部恢复正常（它们本身没坏，
    只是因为 0600-1 整包被跳过而失去上下文）。
  - `qualcommax/0600-4`：6.18.62 在 `bonding.h` 新增
    `bond_peer_notify_work_rearm()` 声明，把 `bond_xmit_hash_without_skb()` 声明
    改插到该行之后。

## 验证方法

- 脚本：`/mnt/syNAS/Dowloads/Rout/mark/verify_gwrt_61862.sh`
  - 真实构建语义 `patch -f -p1`（fuzz=2）；stale 用正向 dry-run 的
    `Reversed (or previously applied)` 判定（`-R -N` 对删除型补丁会误判，已弃用）。
  - 每个 target 用 `cp -al` 硬链接复制基线树，避开 tmpfs 用户配额 6315M。
  - 支持 `SRC` / `KW` / `ONLY_TARGET` 环境变量，可换内核 tarball 做对照。
- 对照：同脚本跑 6.18.60，区分「.62 新引入」与「本来就有」的失败。
- 6.18.60 基线结果：generic 全通过、qualcommax 零失败；ath79 / bcm27xx /
  econet 的若干失败在 .60 上就存在（这些机型当前不构建），与本次无关。

| ramips | 46 | 46 | 0 | 0 | 0 |

- **generic 全层与 SS-01 目标 qualcommax 在 6.18.62 上零硬失败**；fuzz 项在
  真实构建参数 `patch -f -p1`（fuzz=2）下能通过，不中止构建。
- ath79 / bcm27xx / econet 的失败项与 6.18.60 对照结果一致，属于该树长期
  存在、且这些机型当前不构建的老问题；唯一 .62 新增的是
  `bcm27xx/0120-hid-usb-Add-device-quirks-for-Freeway-Airmouse-T3-an.patch`
  （PR #26530 有手工 rebase，但 GWRT 树该补丁与上游基线不同、diff 不可套），
  同样不影响 SS-01，记录待后续随上游对齐。
- 变更合计 32 个文件：2 个删除、30 个修改（`git diff --check` 通过）。
