# WORKLOG 2026-11-18 — GWRT 主题 r123 半小时流量持久化与拓扑机型图片

## 1. 任务背景

用户进一步明确：永久保存的是流量用量的累计数字，不需要每日明细；改为每半小时写入一次路由器 eMMC/NAND 的系统可写分区。首页网络拓扑复用最新 Mesh 包的机型图片，CS-02 与 CS-02-GWRT2 都使用京东云 AX6600 图片，主路由、Mesh AP 以及可识别的接入设备均可显示。保持原有紧凑卡片和导航高度。

本轮 r123 **替代 r122 的按日检查点、400 天日明细及停止服务强制写盘策略**。旧工作日志保留为历史，实际行为以本日志和 r123 源码为准。

## 2. 流量记录实现

- `/etc/gwrt/traffic-daily.json` 沿用原路径，内容升级为 schema v3。只保存总量、今天、本周、本月、本年的 IPv4/IPv6 上下行累计值，以及计数器基线、统计覆盖起点和检查点元数据；没有按日数组、连接明细、瞬时速率或曲线历史。
- 每次采样在内存累计增量，运行状态与最近曲线保存在 `/tmp/gwrt-theme/traffic-state.json`，后台约每 5 秒更新。页面读取不触发持久写入。
- 正常持久化间隔为 1800 秒：写入同目录 `.new` 文件后原子替换，再执行 `/bin/sync`。第一次有效基线、旧 schema 迁移可立即写一次；同一启动内按 uptime 计时，服务重启不绕过间隔。停止服务只更新 `/tmp` 运行状态。
- v1 日明细一次性压缩成当前周期汇总，保留原累计总量；v2 同样保留已有累计。采样失败保留既有值，接口或计数器重置重新建立基线，避免重复累计。
- 固定数量字段覆盖更新，不随使用天数增加文件或记录条目；数字位数变化会使文件大小略有变化。两台实机文件分别为 1041、1035 字节，约 1 KB；这不是底层闪存的实际写放大量。
- 实机挂载确认两台均为 eMMC：系统分区 `mmcblk0p18`，F2FS 可写 `/overlay`，根 overlay 的 upperdir 为 `/overlay/upper`。因此 `/etc/gwrt` 的记录存放在内置 eMMC，不在 `/tmp`。其它 NAND 设备沿用系统正常可写 overlay 路径，不直接写裸分区；NAND 实机未在本轮验证。
- 顶部横栏显示今天、本周及总量；本月、本年保留条件显示。周/月/年需要至少 7/30/365 天有效覆盖且覆盖当前日历周期起点，时间不足时隐藏。周期累计在内存滚动，写盘仍按半小时执行。
- 突然断电可能丢失最近约半小时尚未持久化的增量，磁盘或采集异常可能影响该范围。本轮没有做真实断电或路由器重启测试。

## 3. 拓扑图片与首页显示

图片及机型目录来自 `package/gwrt-wifiroam-v5/files/usr/share/gwrt/wifiroam-v5/res/` 的 `modelart.js` 和 `router/`。

| 识别结果 | 图片 | 资源来源 |
| --- | --- | --- |
| CS-02、CS-02-GWRT2 及对应 JDCloud board/model 名称 | `京东云_AX6600无线宝.png` | 随主题内置 |
| SS-01 及对应 JDCloud board/model 名称 | `京东云_AX1800Pro.png` | 随主题内置 |
| 其它目录内可确定的机型 | 目录中对应产品图片 | 复用 `/luci-static/resources/wifiroam/router/` |
| 未知、歧义机型或图片加载失败 | 原 SVG 图标 | 原有回退 |

新增 `htdocs/luci-static/gwrt/resources/router-models.js`，优先使用 board_name/model，再尝试 hostname/name；保留完整型号边界，避免将只有 AX6000 的信息或 AX6000 Pro 错配到其它产品。首页主路由、Mesh AP、接入设备的拓扑节点都接入同一匹配逻辑。匹配必须有设备实际提供的机型信息，不能只靠 MAC 推断具体型号。

产品图固定为 40 × 40 px，并采用 contain，避免细长 AX1800Pro 图片撑高节点。保留同一卡片中两种颜色的 IPv4/IPv6 曲线，曲线背景透明，协议上下行与累计值照常显示；今天/周期总量移到顶部横栏。活跃 APP 地址使用当前设备地址，避免沿用旧地址。

## 5. 备份与回滚

两台设备均保留 `/root/gwrt-backups/20261118-theme-r123-before/`，含主题 `theme.tgz`、更新前最终统计 `stats-final.tgz`、新增文件清单及 `rollback.sh`。备份也已取回本地证据目录的对应 IP 子目录。

如需回滚，在对应路由器执行：

```sh
sh /root/gwrt-backups/20261118-theme-r123-before/rollback.sh
```

脚本会恢复主题和更新前统计快照，再启动统计服务、清理 LuCI 缓存并 reload uhttpd。**同时会把统计恢复到备份时刻；回滚前需另存当前统计，避免丢失备份后增量。** 本轮未执行回滚。

NAS 源码变更前副本在证据目录 `source-before/`，尺寸修正前备份在 `source-before-sizing-fix/`；文件同步记录见 `source-sync.json`。AGENTS 修改前另存 `AGENTS-before-r123-docs.md`，保留同期其它平台工作。
